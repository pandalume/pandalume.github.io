# tinypanda-collab.github.io

The public website for T Panda Atelier's apps: a home page and the privacy policy that
Google sign-in needs. Served free by GitHub Pages at https://tinypanda-collab.github.io

- `index.html`: home page (https://tinypanda-collab.github.io/)
- `privacy.html`: privacy policy (https://tinypanda-collab.github.io/privacy.html)
- `style.css`: shared styles, light and dark

These two links are used in Google Cloud › Google Auth Platform › Branding (project
jon-apps), with `tinypanda-collab.github.io` as an authorized domain.

When an app changes what data it collects or which services it uses, update `privacy.html`
and its "Last updated" date. When you move to a company domain and email, change the
links on the Branding page and the email addresses here.
